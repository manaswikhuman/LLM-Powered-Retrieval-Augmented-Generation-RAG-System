# LLM-Powered-Retrieval-Augmented-Generation-RAG-System
Designed a RAG-based application integrating large language models with vector search to enable context-aware question answering and knowledge retrieval from custom data sources.
## Tech Stack
- Python
- Streamlit
- LangChain
- OpenAI API
- FAISS

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Create a `.env` file and add your OpenAI API Key:
   ```
   OPENAI_API_KEY=your_api_key_here
   ```
3. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
